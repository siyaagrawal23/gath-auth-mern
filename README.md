# Gath-Assessment

A full-stack MERN Authentication system with JWT Access + Refresh Tokens.

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, Axios
- **Backend**: Node.js, Express.js, MongoDB, JWT, bcrypt
- **Database**: MongoDB Atlas

## Features
- User Signup & Login
- JWT Access Token + Refresh Token
- Password hashing with bcrypt
- Protected Routes
- Responsive UI

## How to Run Locally

1. Clone the repo
```bash
git clone https://github.com/siyaagrawal23/gath-auth-mern.git
```
2. Setup Backend
```bash
cd backend
npm install
```
Create .env file:
```bash
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
PORT=5000
```
```bash
npm start
```
3. Setup Frontend
 ```bash
cd frontend
npm install
npm run dev
 ```

Open localhost:5173
